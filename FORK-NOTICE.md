# Fork notice

This repository is an unofficial fork of
[Supermedo/bloodborne_pc](https://github.com/Supermedo/bloodborne_pc). It restores
**The Hunter's Dream** as the default co-op pool in bbport 1.9.7 and keeps **SuperMedo Server**
as a second choice.

The upstream project is licensed under GPL-2.0-or-later, with GPL-3.0-or-later parts (the online
code adapted from bbhost and the FSR 4.1 launcher files). This fork keeps those licenses and
notices. The launcher patch is built from the source in this repository.

This fork is not affiliated with, endorsed by, or supported by Supermedo, the bbport
contributors, The Hunter's Dream, Sony Interactive Entertainment, or FromSoftware.

- No game files, decrypted dumps, keys, saves, or tokens are distributed here.
- The Hunter's Dream and SuperMedo Server are third-party services with their own rules.
- The Hunter's Dream is a community pool; its operators do not provide support for bbport.
  Please report port problems through the upstream community instead.
- "Bloodborne" is a trademark of Sony Interactive Entertainment. The name is used only to
  describe what this fork is for.

The launcher patch intentionally disables the built-in updater. Upstream releases would replace
the patched launcher with the stock one; update through this fork's releases instead.
